\problem{1}
Any point $(x,y,z)$ on the line is a scalar multiple of the vector $v=(1,-2,3)$:
\begin{equation*}
	(x,y,z)
	=av
	=(a,-2a,3a)
	\iff \left\{ 
		\begin{aligned}
			x&=a \\
			y&=-2a=-2x \\
			z&=3a=3x
		\end{aligned}
	\right.
\end{equation*}
A point is on the line if and only if we can write it in the form $(x,-2x,3x)$, where $x\in\mathbb R$.
